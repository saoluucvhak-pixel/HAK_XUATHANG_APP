# Bản 2.9.9 — File đã tải

Theo bố cục ảnh người dùng cung cấp: nút File đã tải trên thanh đầu, thông báo Đã lưu file kèm tên và đường dẫn thực tế, các nút Mở file / Mở thư mục / Xem file đã tải.

Mỗi lần xuất Word/Excel/ZIP vẫn mở hộp Lưu thành. Sau khi lưu thành công mới thông báo. Mở thư mục sẽ mở Explorer và chọn sẵn file. Lịch sử lưu tối đa 100 đường dẫn gần nhất trên máy, bắt đầu từ bản này; không tự quét những file tải trước đây. Không di chuyển hoặc xóa file khi dùng danh sách. Tệp đã di chuyển/xóa được báo rõ. Hộp lưu lần tiếp theo mở tại thư mục của file gần nhất nếu thư mục còn tồn tại.

PDF qua hộp thoại in của trình duyệt chưa đưa vào danh sách này. Giữ chức năng mở Downloads và tạo thư mục con. Cài xong cần mở lại bằng lối tắt để tiện ích Windows mới chạy.

89 kiểm thử đạt. Đã biên dịch tiện ích và kiểm tra chặn mở đường dẫn ngoài lịch sử. Chưa kiểm tra trực quan giao diện và Explorer trong lượt này.

# Bản 2.11.2 — Báo cáo theo năm

- Trang Báo cáo có ô **Năm** (chọn nhanh 01/01–31/12, tính theo ngày bắt đầu hồ sơ), bảng **Theo năm** và sheet Excel **Theo năm**.
- Tên file Excel xuất có kỳ báo cáo, ví dụ `BaoCaoTongHop_Nam2025_xuat20261018.xlsx`.
- Bộ cài Windows (NSIS) được dựng tự động trên GitHub Actions: `HAK_QuanLyXuatHang_Setup_v2.11.2.exe`; lối tắt mở `native\HAKDocs.exe`; không kèm công cụ mở khóa / xóa dữ liệu.
- Chưa ký số bộ cài; chưa kiểm tra cài đặt trên máy Windows thật.

## Báo cáo theo năm
Trang Báo cáo có ô **Năm** (chọn nhanh 01/01–31/12, tính theo ngày bắt đầu hồ sơ), bảng và sheet Excel **Theo năm**; tên file xuất có kỳ báo cáo, ví dụ `BaoCaoTongHop_Nam2025_xuat20261018.xlsx`.
